# Minhas notas de Git

O ciclo é: edita → status → add → commit
Repetir varias vezes para fixar
testando git diff
Comando O que faz
git init Cria o repositório na pasta
git status Mostra o que mudou e o que está na staging
git add arquivo / git add . Coloca na staging (o . = tudo)
git commit -m "msg" Tira a foto com legenda
git log --oneline Lista os commits resumidos
git diff / git diff --staged Mostra diferenças (antes/depois do add)
git remote add origin URL Conecta ao repositório remoto
git push -u origin main Envia commits para o GitHub
git restore arquivo Desfaz alterações não commitadas
git branch / git checkout nome Lista / troca de branch
